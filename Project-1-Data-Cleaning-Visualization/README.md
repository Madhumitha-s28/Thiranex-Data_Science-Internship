# Data Cleaning and Visualization Project

## Overview
This project was completed as part of my **Data Science Internship at Thiranex EduTech LLP**.

The main objective of this project is to understand the process of cleaning a raw dataset, preparing it for analysis, and creating visualizations to identify useful patterns and insights.

## Objectives
- Load and explore the given dataset.
- Identify and handle data quality issues.
- Perform data cleaning and preprocessing.
- Detect and remove outliers using the Interquartile Range (IQR) method.
- Prepare categorical data for analysis.
- Create visualizations to understand the dataset.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

### 1. Data Loading and Exploration
Loaded the dataset using Pandas and explored its structure, columns, and basic information.

### 2. Data Cleaning and Preprocessing
Performed the necessary data cleaning operations to prepare the dataset for analysis.

### 3. Outlier Detection and Removal
Used the Interquartile Range (IQR) method to identify and filter outliers in the Salary column.

### 4. Categorical Data Processing
Converted department-related categorical columns into integer format for analysis.

### 5. Data Visualization
Created the following visualizations:
- Department Distribution – Bar chart showing employee distribution across departments.
- Salary Distribution – Histogram showing the distribution of salaries.
- Salary vs. Age – Line plot illustrating the relationship between age and salary.
- Salary vs. Age by Department – Scatter plot comparing employees across departments.

## Repository Contents

| File | Description |

## How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open `Data_cleaning.ipynb` using Jupyter Notebook.
4. Make sure the CSV dataset is available in the same folder as the notebook.
5. Run the notebook cells in sequence.
